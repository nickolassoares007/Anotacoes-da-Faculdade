## 🧰 Principais Atalhos & Comandos

| Comando / Atalho | Função | Onde | Comentário |
|------------------|--------|------|------------|
| `Ctrl + Shift + P` | Abre a Paleta de Comandos | VS Code | Acesso rápido a tudo |
| `Ctrl + '` | Abre o terminal integrado | VS Code | Terminal sem sair do editor |
| `Ctrl + S` | Salvar arquivo atual | VS Code | Instintivo |
| `Ctrl + W` | Fecha a aba atual | VS Code | Organiza o caos |
| `cls` / `clear` | Limpar terminal | Terminal | Mantém a visão limpa |
| `git init` | Inicia um repositório Git | Git | Ativa o controle de versão |
| `git clone <url>` | Clona repositório remoto | Git | Traz projeto + histórico |
| `git status` | Mostra mudanças | Git | Comando mais usado do Git |
| `git add .` | Adiciona tudo ao stage | Git | Prepara para commit |
| `git commit -m "msg"` | Cria um commit | Git | Salva o progresso |
| `git push` | Envia commits ao GitHub | Git | Publica alterações |
| `git pull` | Baixa atualizações do remoto | Git | Sincroniza com o time |
| `git branch` | Lista branches | Git | Mostra as linhas de trabalho |
| `git checkout -b <nome>` | Cria e troca para uma branch | Git | Fluxo moderno |
| `git merge <branch>` | Mescla branches | Git | Junta alterações |

## 📝 Principais Recursos do Markdown

| Recurso | Sintaxe | Resultado / Uso |
|--------|---------|------------------|
| **Títulos** | `# Título` <br> `## Subtítulo` | Organizam o texto em níveis hierárquicos. |
| **Negrito** | `**texto**` | Realça termos importantes. |
| **Itálico** | `*texto*` | Ênfase leve, ideal para conceitos. |
| **Código inline** | `` `codigo` `` | Usado para trechos curtos de código ou comandos. |
| **Bloco de código** | <code>```linguagem<br>código<br>```</code> | Destacado, com highlight da linguagem (Python, JS, etc.). |
| **Listas ordenadas** | `1. Item` | Sequências lógicas, passos, algoritmos. |
| **Listas não ordenadas** | `- Item` ou `* Item` | Pontos soltos, tópicos gerais. |
| **Links** | `[texto](url)` | Conecta documentos e páginas externas/internas. |
| **Imagens** | `![alt](caminho)` | Ilustra setups, diagramas, prints do projeto. |
| **Citações** | `> texto` | Comentários, notas, lembretes técnicos. |
| **Linha horizontal** | `---` | Separa seções visualmente. |
| **Tabelas** | `| Col | Col |` | Organização de dados estruturados. |
| **Checkboxes** | `- [ ] tarefa` | To-dos, etapas de estudo, features do projeto. |
| Comentario invisivel | `<!-- Este comentário não aparece na visualização -->` | Bom para quando quer colocar um comentario que não vai aparecer |
